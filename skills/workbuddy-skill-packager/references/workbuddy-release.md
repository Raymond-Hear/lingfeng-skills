# WorkBuddy 内容复核与头像

## 先完成内容和 ZIP

先产出并检查 WorkBuddy 版 ZIP。当前正在 WorkBuddy 内工作，或已有可用的 WorkBuddy 会话时，把需要复核的公开版正文和元信息交给 WorkBuddy。请它核对名称、简介、示例是否与核心能力一致，并指出输入要求、依赖和输出有没有写清楚。按源 Skill 核实建议，采用后重新打包。当前无法接入 WorkBuddy 时，先完成本地适配和检查，交付 ZIP，说明平台复核的状态。

可用这句话开启 WorkBuddy 复核。

> 请复核这份准备提交到 WorkBuddy 开放平台的 Skill。检查名称、简介和示例是否准确反映实际用途，核对用户需要提供的资料、运行依赖和能得到的结果。请给出可以直接替换的文案，并指出你无法核实的能力。

## 再选头像

定稿后交付 ZIP，同时请用户从已提供的候选图里选一张，或在当前聊天上传原图。用户已经指定原图时直接处理。准备上传到开放平台时，把 ZIP 和头像作为两份文件。进入技能表单后，以该表单显示的具体限制为准。开放平台要求资产头像是和定位相符、能辨认的图形。 [开发者公约](https://open.workbuddy.cn/docs/developer-agreement)

- 输出 **512×512 px**。优先 PNG。把 **500 KB** 用作默认压缩目标，这个数值来自官方公开的专家头像规范。技能上传页面如果给出具体的格式或大小限制，就按该页面调整。 [WorkBuddy 专家头像规范](https://open.workbuddy.cn/docs/expert#头像规范)
- 方图等比缩放。横图或竖图默认居中补边，保留完整图案。原图构图适合裁剪且用户要求铺满时，可居中裁成正方形。先看预览里的人脸、文字或标识是否完整。
- 输出 PNG 超过大小目标时，可以转为 JPG 压缩。如果 JPG 需要给透明区加背景，默认白色，并在交付时说明。需要保留透明时，继续用支持 PNG 压缩的工具。交付前回读并检查实际宽、高、格式和大小。

## 在 Windows 上整理原图

```powershell
pwsh -NoProfile -File "<Skill目录>/scripts/prepare_avatar.ps1" -InputPath "<原图>" -OutputDirectory "<ZIP所在目录>"
```

脚本支持 `-Mode Crop` 居中裁剪、`-MaxBytes 500000` 调整体积目标和 `-KeepTransparency` 只输出 PNG。默认保留完整构图。Windows 上使用 PowerShell 与系统图片组件。若环境不支持或图片格式无法读取，用环境里的图像工具处理，再回读核对尺寸和大小。

用户授权操作开放平台时，在技能表单分别上传最终 ZIP 和处理好的头像，核对文件和预览。按当次请求保存或提交，并回读平台状态。
