## 询问调整需求

向用户提出以下问题以便进一步优化：

### 问题1：详细程度调整
```
这个提示词的详细程度是否符合你的需求？

A. 快速版 - 简化框架，快速获取核心信息
B. 标准版 - 当前版本（推荐）
C. 完整版 - 更深入的框架和分析要求

[当前：标准版]
```

### 问题2：维度调整
```
是否需要调整优化维度？

你可以：
- 移除某个维度（如不需要输出格式要求）
- 增强某个维度（如需要更详细的子问题）
- 保持当前配置

[当前包含：研究框架、子问题拆解、信息来源指引、输出格式]
```

### 问题3：平台优化
```
是否针对特定工具进行优化？

A. Perplexity - 强化实时搜索和来源引用
B. OpenAI Research - 强化深度分析和综合能力
C. 千问深度研究 - 强化中文内容和本地化信息
D. 保持通用版本
```

### 问题4：输出格式调整
```
是否需要调整输出格式？

当前格式：[摘要 + 详细分析 + 数据 + 来源]

可选调整：
- 更简洁（仅摘要+关键点）
- 更详细（增加对比表格、图表说明）
- 自定义格式
```

## 根据反馈调整

### 场景1：调整为快速版
- 简化研究框架（保留核心结构）
- 减少子问题数量（2-3个）
- 简化输出格式（摘要+关键点）
- 保持信息来源指引

### 场景2：调整为完整版
- 增强研究框架（添加对比分析、风险评估等）
- 增加子问题数量（5-7个）
- 扩展输出格式（增加对比表、时间线图等）
- 增加信息来源要求

### 场景3：针对Perplexity优化
```
【Perplexity优化版】
- 强调"实时搜索最新信息"
- 强调"引用具体来源链接"
- 强调"标注发布时间"
- 添加"多源验证要求"
```

### 场景4：针对OpenAI Research优化
```
【OpenAI Research优化版】
- 强调"深度分析"和"综合评估"
- 强调"多角度思考"
- 强调"批判性思维"
- 添加"不确定性说明"
```

### 场景5：针对千问深度研究优化
```
【千问深度研究优化版】
- 强调"中文信息源优先"
- 强调"本地化情况"
- 添加"国内政策/环境考量"
- 使用中文表达习惯
```

### 场景6：移除特定维度

**移除输出格式要求：**
```
# 研究框架
[保留]

# 核心问题
[保留]

# 信息来源
[保留]

# 输出要求
请自由组织内容，确保覆盖上述要点即可。
```
